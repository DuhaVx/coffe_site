# Обводный Канал

Учебный проект для портфолио: одностраничный сайт петербургской кофейни с простой корзиной на `localStorage` и отдельной SQL-частью на PostgreSQL.

## Идея

Кофейня находится рядом с Обводным каналом, в старом фонде. Визуально проект собран в темной палитре с ржаво-оранжевым акцентом: кирпич, металл, спокойный свет, локальная выпечка и кофе "для своих".

## Что реализовано

- `Hero`-блок с атмосферным фоном и слоганом
- Блок `Меню` с карточками и добавлением в корзину
- Модальное окно корзины
- Сохранение корзины в `localStorage`
- Секция `О нас` с намеренно неровной "студенческой" версткой абзацев
- Секция `Контакты` с `iframe` Яндекс.Карт
- Пасхалка по клику на логотип
- Случайная фраза дня в футере

## Стек

- HTML
- CSS
- JavaScript (без фреймворков)
- Node.js (локальный сервер)
- PostgreSQL

## Структура проекта

- `index.html` — вся разметка одностраничника
- `style.css` — стили сайта
- `script.js` — логика корзины, localStorage, пасхалка, фраза дня
- `database.sql` — схема БД + индексы + триггер + стартовые данные
- `demo-data.sql` — расширенные демо-данные для аналитики
- `queries.sql` — готовые SQL-запросы для демонстрации
- `PRESENTATION.md` — короткий текст выступления на защиту
- `server.js` — локальный HTTP-сервер на Node.js
- `package.json` — запуск сервера через `npm start`

## Как запустить фронтенд

Запуск через локальный сервер на JavaScript (Node.js):

```bash
node server.js
```

После запуска:

- [http://localhost:3000](http://localhost:3000)

Альтернатива через npm-скрипт:

```bash
npm start
```

## Как запустить SQL-часть

1. Создать пустую базу в PostgreSQL
2. Выполнить схему и начальные данные
3. При необходимости добавить расширенные демо-данные
4. Выполнить аналитические запросы

```bash
psql -U your_user -d your_db -f database.sql
psql -U your_user -d your_db -f demo-data.sql
psql -U your_user -d your_db -f queries.sql
```

## Что можно показать на защите

- Корзина работает без бэкенда за счет `localStorage`
- Есть продуманная SQL-схема с ограничениями и индексами
- Сумма заказа автоматически пересчитывается через триггер
- Есть выборка для витрины меню (`menu_showcase`)
- Подготовлены аналитические запросы по продажам и выручке
